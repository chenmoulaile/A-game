# LAST STAND / 最后防线

雨夜末日军事题材的网页端 3D 第一人称射击战役。游戏入口位于 `dist/index.html`；完整源码与构建工程打包在 `work/last-stand-source.zip`。

## 在线游玩

打开 GitHub Pages 发布的 `/dist/` 路径，或下载 `dist/index.html` 后通过本地静态服务器打开。当前单文件包使用 Three.js r180 官方 CDN 模块，首次运行需要网络访问 CDN。游戏模型、场景、材质效果和音效均为程序化生成，不下载外部美术素材。

本地运行：
```bash
python -m http.server 8000
```
然后打开 `http://localhost:8000/dist/`。

## 战役与系统

- 五幕主线：展览日、正门防线、防线突破、内场与看台、终幕命令。
- 五把武器：M4A1、MP5K、M110、M870、P226，各自拥有射速、伤害、散布、后坐与换弹参数。
- 五类感染体：普通感染者、Runner、Brute、Spitter、Heavy；包含拟人模型、头部弱点、追击与攻击动作。
- 24 名友军单位自动交战；角色包含队长、医疗兵、破门手、机枪组与步枪兵。
- 可选支线：接通应急广播、救出被困坦克乘员；完成两项支线可触发 H1 隐藏结局。
- 七种正向结局：S1—S3、E1—E3、H1。机枪组在所有结局留守；三辆坦克一辆死守、两辆撤离，乘员存活。
- 结局评分：平民救援 0.5、坦克完好度 0.2、坚守时长 0.18、机枪组留守时长 0.12。

## 完整源码与测试

解压 `work/last-stand-source.zip`，进入解压后的 `work` 目录：

```bash
npm test
npm run build
```

构建产物写入仓库根目录的 `dist/index.html`。测试使用 Node.js 内置测试运行器，无需安装测试框架；构建脚本使用 Node.js 内置 API，无需 NPM 构建依赖。

## 技术边界

- Three.js r180 由官方 CDN 加载；若离线运行，需要自行将 Three.js 模块本地化并调整构建脚本。
- 单机本地战役，无联网联机、账号或云存档。
- AI 已实现感知 Blackboard、FSM 最短驻留/排队、空间哈希分离等模块；场景实时追击使用直接追击与局部避让。A* 网格寻路工具已独立测试，但当前战斗单位未全部切换为 A* 导航。
- 由于当前自动化执行容器无法访问外部 CDN，已验证核心单元测试与静态构建；真实 WebGL 渲染仍需在可访问 CDN 的桌面浏览器复核。
